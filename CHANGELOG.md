# Changelog

## 0.2.0-alpha.1

- Add lazy Audio and Graphics section contracts.
- Inventory PipeWire-Pulse outputs, inputs, streams and cards behind stable
  opaque IDs without exposing raw backend identities.
- Add exact-acknowledgement default audio planning, mutation and verification.
- Inventory DRM GPUs with stable opaque IDs and Mesa/NVIDIA strategy labels.
- Add private atomic default, exact-executable and canonical directory-prefix
  GPU policy with exact-over-longest-prefix resolution.
- Explicitly defer launch enforcement, display-GPU changes and running-process
  migration to independent gates.

## 0.1.0-alpha.1

- Publish the standalone CLI-first settings inventory.
- Expose semantic layers, package versions and generated live drift as v2 JSON.
- Keep optional Docker inspection direct-argv, bounded and non-mutating.
- Add version reporting and deterministic headless fixtures.
